## 1. 概述：什么是 Trae

### 1.1 基本定位

**Trae**（全称：The Real AI Engineer）是字节跳动于 2025 年推出的**国内首个 AI 原生集成开发环境（AI IDE）**。其核心理念是"让每个开发者都能用得顺的 AI 辅助工具"，主打中文适配和轻量化体验。

与传统 IDE 不同，Trae 的核心优势是"AI 协同"。它不是简单地在编辑器中加入 AI 功能，而是从底层架构就将 AI 能力深度整合到开发流程的每个环节。Trae 能理解需求、调用工具、独立完成各种开发任务，帮助你高效推进每一个项目。

**核心定位**：可理解需求、调用工具、完成开发任务的智能协作引擎。区别于传统 IDE 的基础 AI 补全功能，Trae 通过大模型与开发全流程的深度融合，实现从需求到部署的端到端自动化。

### 1.2 版本与模型

## 2. 安装与配置

### 2.1 下载安装

**访问官网**：
- 国内用户：[https://www.trae.cn/](https://www.trae.cn/)
- 海外用户：[https://www.trae.ai/](https://www.trae.ai/)

**下载安装包**：
- Windows：`.exe` 安装程序（约 100MB）
- macOS：`.dmg` 文件，支持 Apple Silicon 和 Intel 芯片
- Linux：`.deb` 或 `.rpm` 包

**安装注意事项**：
- Windows 用户若提示 `MSVCP140.dll` 缺失，需安装 [VC++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe)
- macOS 系统版本需在 12.0 及以上
- 国内用户务必使用 trae.cn 域名

### 2.2 首次启动配置

1. **选择主题和语言**：推荐选择深色主题（保护眼睛），语言默认简体中文
2. **导入配置（可选）**：支持从 VS Code 或 Cursor 导入现有配置，包括插件、主题、快捷键
3. **登录激活**：点击右上角"登录"，支持手机号注册/登录，登录后才能激活 AI 功能

### 2.3 模型切换

登录完成后，在右侧 Chat 面板顶部的下拉菜单中可以切换模型：
- 代码生成优先选 DeepSeek R1
- 对话优化选豆包 1.5 Pro
- 复杂推理任务选 GLM-5

## 3. 核心功能详解

### 3.1 代码补全（Code Completion）

Trae AI 可以理解当前代码，然后提供建议补全的代码。

**触发方式**：
- 在对应代码处，敲击回车键换行，AI 会阅读并理解当前代码，自动补全后续代码
- 在对应位置添加注释，然后敲击回车键换行，AI 会根据注释生成代码

**采纳方式**：
- 点击 **接受** 按钮或按下 Tab 键，添加所有推荐的代码
- 点击 **接收 Word** 按钮或使用 Ctrl + → 快捷键，逐字添加推荐的代码
- 按下 Esc 键，清除推荐的代码

**代码补全 Pro（Beta）**：
- 基于上一次的编辑内容及当前代码情况，预测下一个代码改动点并提供推荐的代码
- 触发快捷键：macOS 为 Control + Shift + Enter，Windows 为 Ctrl + Shift + Enter

### 3.2 代码生成（Code Generation）

Trae AI 可以根据自然语言描述生成对应的代码片段。

**操作步骤**：
1. 在输入框中用自然语言描述需求
2. 点击发送按钮或敲击回车键
3. AI 开始生成所需代码片段

**代码片段操作**：
- 点击 **复制** 按钮，复制代码片段
- 点击 **插入** 按钮，将代码片段插入至对应位置
- 点击 **添加文件** 按钮，将代码片段生成为一个单独的文件
- 点击 **Apply** 按钮，将生成代码以 Diff 的形式展示在原文件中

**实用技巧**：输入指令标注「语言+需求+细节」，例如：`Python 读取CSV并计算销售额平均值，保留2位小数`

### 3.3 代码编辑（Code Editing）

Trae AI 可以编辑指定代码，包括重构、优化、修改部分逻辑等。

**操作步骤**：
1. 选中待修改的代码片段
2. 在对话框中输入自然语言描述，例如："优化选中的代码片段"
3. 点击发送按钮或敲击回车键
4. AI 开始修改代码并生成新的代码片段

### 3.4 代码解释（Code Explanation）

选中代码片段后，可以向 Trae AI 发送代码解释指令。

**发送指令方式**：
- 在侧边对话视图的输入框中输入自然语言描述，例如："解释选中的代码片段"
- 在侧边对话视图的输入框中输入 `/explain` 指令
- 选中代码片段后右键，选择 **Trae AI > 代码解释**
- 点击代码文件顶部的 **解释代码** 按钮

### 3.5 单元测试生成（Unit Test Generation）

选中代码片段后，向 Trae AI 发送单元测试生成指令。

**发送指令方式**：
- 在侧边对话视图的输入框中输入自然语言描述，例如："为所选代码片段生成单元测试"
- 在侧边对话视图的输入框中输入 `/test` 指令
- 选中代码片段后右键，选择 **Trae AI > 单测生成**
- 点击代码文件顶部的 **生成单测** 按钮

### 3.6 代码注释生成（Code Documentation）

选中代码片段后，向 Trae AI 发送代码注释生成指令。

**发送指令方式**：
- 在侧边对话视图的输入框中输入自然语言描述，例如："为所选代码片段生成注释"
- 在侧边对话视图的输入框中输入 `/doc` 指令
- 选中代码片段后右键，选择 **Trae AI > 注释生成**
- 点击代码文件顶部的 **生成注释** 按钮

> **提示**：Trae AI 默认生成函数级注释，你可以通过自然语言指定生成更详细的行间注释。

## 4. 两种开发模式

### 4.1 IDE 模式

IDE 模式保留原有的工作流程，提供更大的控制力。在这种模式下：
- 你主导开发过程，AI 作为辅助工具提供建议和补全
- 可以随时使用 AI 能力，但决策权在你手中
- 适合需要精细控制的开发任务

### 4.2 SOLO 模式

SOLO 模式是 Trae 最强大的功能，让 AI 主导任务，自动推进开发工作。

**SOLO Coder**：
- 面向复杂项目开发的智能体
- 能够助力完成从需求迭代到架构重构的全流程开发工作
- 支持 Plan Mode，先讨论方案再执行
- 支持协调多个子智能体处理不同任务

**SOLO Builder**：
- 快速构建专业级、功能完整的 Web 应用
- 只需用自然语言描述需求，Builder 会自动：
  1. 选择最合适的 AI 模型
  2. 分析需求
  3. 生成 PRD
  4. 编写代码
  5. 产出可预览的结果

**SOLO 模式的核心特点**：
- **响应式审查**：查看 AI 做出的每个决策，可随时重定向
- **响应式上下文**：AI 看到的内容与你一致，上下文保持可见、相关且自适应
- **响应式多任务**：支持多智能体并行运行，同时保持完全可见性

### 4.3 模式切换

可根据任务需求自由切换：
- 想自己掌控代码走向 → 选择 **IDE 模式**
- 想让 AI 全流程托管 → 选择 **SOLO 模式**
- 切换快捷键：macOS 为 Cmd+Shift+S，Windows 为 Ctrl+Shift+S

## 6. 智能体系统与自定义

### 6.1 创建自定义智能体

Trae 提供开放式智能体框架，你可以：

1. **从内置智能体开始**：使用内置的智能体完成常见任务
2. **创建自定义智能体**：根据特定工作流程定义智能体的工具、技能和逻辑
3. **部署为独立智能体或子智能体**：可以单独使用，也可以让其他智能体调用
4. **构建智能体团队**：创建多个专业化智能体，协同处理复杂任务

### 6.2 MCP 工具集成

Trae 支持 Model Context Protocol（MCP），可以访问外部资源：
- 安装 MCP 工具：`sequential-thinking`（多步骤推理）和 `Puppeteer`（网页自动化）等
- 智能体可以按需调用外部资源

### 6.3 规则引擎

在 `.t Rae/rules` 中配置团队编码规范和安全规则，AI 生成代码自动合规：
- 强制 TypeScript 类型检查
- 禁用 eval()
- 安全规范约束
- 代码风格统一

**适用场景**：
- 金融团队统一安全规范
- 教学场景约束学生代码风格
- 团队代码审查效率提升

### 6.4 冲突解决

多人协作时，开启"实时冲突检测"：
- AI 自动标记差异
- 给出合并建议
- 大型项目协作效率提升 80%

## 7. Prompt 工程最佳实践

### 7.1 Agent 类 Prompt 的核心要素

根据 Anthropic 的最佳实践，Agent 类 Prompt 应包含：

| 要素 | 说明 | 示例 |
|------|------|------|
| **角色与高层目标** | 1-2 句话说明你是谁、为啥而来 | "你是后端开发专家，擅长 Python 和数据库设计" |
| **动态上下文** | 检索到的资料、用户偏好、会话历史 | 从代码库中提取的相关文件内容 |
| **详细任务指令** | 做什么、不做什么、成败标准 | "生成一个 RESTful API，包含用户注册和登录功能" |
| **示例（可选）** | 边界提醒，用于示例学习 | 提供一个类似功能的完整代码示例 |
| **重复关键指令** | 长提示里防止遗忘 | "确保所有函数都有类型注解" |

### 7.2 推理模式

**ReAct 模式（Reasoning + Acting）**：
```
Thought: [分析当前情况，决定下一步做什么]
Action: [选择并执行特定动作]
Observation: [分析动作的结果]
继续循环直到得到最终答案
```

**Chain-of-Thought 模式**：
1. 问题理解：用自己的话重述问题
2. 信息收集：需要什么信息？
3. 分析：将问题分解为更小的部分
4. 解决方案开发：系统地处理每个部分
5. 验证：检查推理和结果
6. 最终答案：提供清晰、可操作的响应

### 7.3 高效 Prompt 技巧

| 技巧 | 说明 | 示例 |
|------|------|------|
| **明确角色** | 指定 AI 扮演的专家角色 | "你是一个 Python 后端开发专家" |
| **具体描述** | 详细说明需求和约束 | "用 Flask 框架，SQLite 数据库，支持 JWT 认证" |
| **分步指导** | 复杂任务分解为步骤 | "首先创建数据库模型，然后实现 API 路由" |
| **提供示例** | Few-shot prompting | 展示一个类似输入输出的例子 |
| **指定输出格式** | 明确期望的输出结构 | "以 JSON 格式返回，包含 code、message、data 字段" |
| **约束条件** | 明确边界和限制 | "不超过 100 行代码，不使用第三方库" |

### 7.4 Trae 专用 Prompt 技巧

| 场景 | Prompt 示例 |
|------|-------------|
| 代码生成 | "Python 读取 CSV 并计算销售额平均值，保留 2 位小数" |
| Bug 修复 | "修复这个空指针异常，错误日志：[粘贴日志]" |
| 代码优化 | "优化 utils.py 中的 MD5 计算函数，提高性能" |
| 项目生成 | "基于 Vue3 的电商后台，带登录权限，适配 Docker 部署" |
| 代码解释 | "用中文解释这个算法的原理" |

## 8. 实战技巧与案例

### 8.1 案例 1：10 分钟生成贪吃蛇游戏

**步骤**：
1. 打开 Trae，点击右侧 **Builder** 标签
2. 输入："创建一个基于 Python 的贪吃蛇游戏"
3. AI 自动生成 `snake_game` 文件夹，包含 `main.py`、资源文件、依赖清单
4. 点击"运行"按钮，AI 自动检测环境并安装依赖
5. 运行后发现问题（如蛇移动太慢），输入："蛇的移动速度太慢，调整为 15 帧/秒"

**关键技巧**：直接拖拽终端报错信息到对话框，AI 精准定位问题。

### 8.2 案例 2：20 分钟生成员工考勤统计工具

**步骤**：
1. 选中整个项目文件夹
2. 提问："添加按部门统计考勤的功能"
3. AI 自动修改 `src/calculator.py` 并新增 `department_report.csv`
4. 点击编辑器右侧"预览"按钮，直接在 IDE 内查看 Web 界面效果

**亮点**：
- 多文件上下文理解
- 可视化预览
- 历史回溯（一键回退代码）

### 8.3 案例 3：看图写代码

**适用场景**：设计师与前端协作

**步骤**：
1. 上传网页设计图（高清标注稿）
2. 输入："生成对应的 React 组件，适配 PC+移动端"
3. AI 自动解析布局结构，生成响应式 HTML/CSS 代码

### 8.4 案例 4：搭建本地知识库

**步骤**：
1. 导入 Markdown/CSV 文件（如学习笔记、简历）
2. 创建知识库智能体
3. 输入提示词："从文档中提取 5 个避免亏钱的方法，并用 Apple 官网风格排版"

### 8.5 高级技巧

| 技巧 | 操作方法 |
|------|----------|
| **上下文引用** | 拖拽文件到对话框，AI 自动理解项目语境 |
| **多模态开发** | 上传设计图/原型图直接生成代码 |
| **锁定上下文** | 用 `#文件名` 指定需操作的代码段 |
| **截图调试** | 上传报错截图，AI 自动定位问题 |
| **历史回溯** | 点击对话历史中的版本，一键回退代码 |

## 9. 常见问题与解决方案

| 问题 | 解决方案 |
|------|----------|
| 中文注释乱码 | 设置 → 文件编码 → 强制 UTF-8 |
| 依赖安装失败 | 切换镜像源：`trae config set npm.registry https://registry.npmmirror.com` |
| 模型生成慢 | 切换至 DeepSeek R1（代码生成优先选择） |
| AI 理解偏差 | 明确指定语言、框架、约束条件 |
| 大文件处理 | 拆分为多个小文件分别处理 |
| 代码风格不一致 | 在 `.trae/rules` 中配置团队规范 |
| 3D 游戏支持弱 | 需结合 Unity 开发 |
| 团队协作功能待完善 | 暂推荐个人原型开发 |
